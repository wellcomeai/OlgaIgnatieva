# Бренд VisaNews2U

- `visanews2u-original.jpg` — исходный логотип (640×640, белый фон).

Готовые ассеты для сайта лежат в `frontend/public/brand/`:

| Файл | Назначение |
|---|---|
| `logo.svg` / `logo-dark.svg` | Полный логотип (знак + надпись) для светлого / тёмного фона |
| `mark.svg` / `mark-dark.svg` | Только знак (галочка с самолётом) |
| `wordmark.svg` / `wordmark-dark.svg` | Только надпись VISANEWS2U |
| `logo.png` | Полный логотип, PNG с прозрачным фоном, 1589×715 |
| `mark.png` | Знак на белой скруглённой плашке, 512×512 (аватар бота, соцсети) |

Фавиконки — `frontend/public/favicon/`. В интерфейсе логотип выводится
компонентом `frontend/src/components/brand/BrandLogo.tsx`.

## Цвета

| | HEX | Где |
|---|---|---|
| Тёмно-синий | `#2B2E81` | Основной: кнопки, ссылки, `--primary` |
| Голубой | `#069DDF` | Акцент: подсветки, фокус, градиенты |
| Индиго (тёмная тема) | `#7C82F2` | Тёмно-синяя часть знака на тёмном фоне |

SVG получены векторизацией исходника: фон удалён (белый самолёт и
внутренности букв сохранены корректно), цвета сведены к фирменным.
